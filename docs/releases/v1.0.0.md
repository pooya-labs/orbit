# ORBIT v1.0.0 — Stable Portfolio Demo

ORBIT v1.0.0 is the first stable release of the public portfolio dashboard and its zero-cost synthetic Apps Script demo runtime.

## What's included

- Responsive observability workspace with Overview, Incidents, Alerts, Notifications, Deployments, SLOs, Audit, Metrics, Logs, and Traces views.
- English and Persian localization, correct RTL layout, persistent dark/light themes, responsive navigation, keyboard support, and table alternatives for charts.
- Google Apps Script V8 demo runtime with a private owner-owned Google Spreadsheet, pseudonymous browser-profile workspaces, short-lived session capabilities, request/body/storage quotas, and a fixed-origin iframe bridge.
- Synthetic demo records and bounded simulated Metrics, Logs, and Traces; notification deliveries are simulation-only and never send real webhooks, email, or external calls.
- Automated CI coverage for the Apps Script contracts/runtime, 22 Chromium interaction and accessibility tests, 76 source accessibility checks, Go API, local OTLP pipeline, workspace A/B isolation, PostgreSQL backup/restore, PostgreSQL restart recovery, and Windows NVDA Browse Mode navigation.
- A documented zero-cost architecture. No paid provider, billing-enabled cloud project, paid domain, or production identity service is required for the public demo.

## Live entry points

- Static dashboard: https://pooya-labs.github.io/orbit/
- Source repository: https://github.com/pooya-labs/orbit

The Apps Script Web App deployment URL is owner-controlled and is intentionally not embedded in this public release artifact. The project owner supplied that URL separately. The verification environment could not fetch `script.google.com`, so this release does not claim an independently verified live Google-hosted bootstrap or mutation.

## Important limitations

- GitHub Pages serves the static frontend; it does not host the Go API, PostgreSQL, Prometheus, Loki, or Tempo.
- The public Apps Script runtime is a portfolio demo using synthetic data only. Do not enter customer, personal, credential, or production telemetry.
- Each browser profile has an isolated synthetic workspace. Spreadsheet storage is private to the deploying account. Google Apps Script quotas and runtime limits apply.
- Notifications show synthetic delivery history only. No outbound webhook, email, or messaging provider is contacted.
- The repository's Go/PostgreSQL/OTel stack is available for local development and CI, but it is not a deployed production service.
- The deferred production Keycloak identity image is scanned independently by the scheduled production-identity workflow; it is not part of the Pages + Apps Script v1 demo or its release gate.
- Automated axe/Playwright and Windows NVDA tests passed, but this release does not claim formal WCAG conformance. Human TalkBack/VoiceOver sessions and broad capacity testing remain post-v1 work.

This release is stable for the stated portfolio-demo scope. It is not a production observability service, a multi-tenant customer-ingestion platform, or evidence of real telemetry collection.
